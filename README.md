# Netflux
Netflix clone built with React (Redux, Router) and The Movie DB API.

## Stack
* HTML5
* CSS3
* JS (ES6+)
* React
* Redux 
* React Router
* Vite
* TMDB

## Getting Started

### Dependencies
* [TMDB](https://developer.themoviedb.org/docs/getting-started)

### Executing program
Clone repository:
```
git clone https://github.com/Lirmortoch/netflusk.git
```
Install dependencies:
```
npm install
```
Run the server
```
npm run dev
```
